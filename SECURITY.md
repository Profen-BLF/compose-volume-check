# Security policy

Report suspected vulnerabilities privately using **Report a vulnerability** on the [GitHub Security advisories page](https://github.com/Profen-BLF/compose-volume-check/security/advisories). If you cannot use private reporting, open an issue asking for a private contact and share the technical details through the private channel.

Include the affected release or commit, the impact, and the commands and synthetic inputs needed to reproduce the issue. Replace credentials, host paths, and private identifiers with dummy values before sharing any input or output.

For ordinary bugs and non-sensitive configuration regressions, follow the [contribution guide](CONTRIBUTING.md).
